# FOUNDER Brand Skill

Read `../../../brand/FOUNDER_BRAND_OS.md` and the project `CLAUDE.md` before making brand-facing changes.

## Mandatory checks
- Preserve FOUNDER > LALALOCA hierarchy.
- Treat FOUND HER as a core community/editorial engine.
- Use the approved visual and photography sources before inventing new visual language.
- Prefer restrained, cinematic luxury over generic DTC polish.
- Keep product clarity and conversion strong even when using room/door storytelling.
- Route product efficacy/skin claims through `claims-compliance`.
- Route material site changes through `brand-council-auditor`.
