# Full Site Audit Workflow

Run in this order:
1. Founder Chief scopes goals and current constraints.
2. Creative Director audits visual world and consistency.
3. UX/CRO audits journey page-by-page and mobile first.
4. Copy agent audits voice, clarity, repetition, claims, CTA hierarchy, SEO usefulness.
5. Product agent audits assortment/navigation/PDP merchandising.
6. FOUND HER agent audits community integration.
7. Claims agent reviews risky claims.
8. Frontend engineer maps implementation dependencies and protects backend mechanisms.
9. Implement in coherent batches.
10. Brand Council performs final red-team review.

Output one prioritized change list:
- now;
- next;
- later.
Each item must include expected customer/business impact and implementation scope.
